# 🧠 [Controller 설계서] 생각나무(Markmap) 질의 중심 뿌리 계층화 및 성단형 세션 포커스 컨트롤러

본 문서는 사용자가 신규로 질의한 프롬프트가 생각나무(Markmap)의 최상위 **뿌리(Root)**로 정립되고, 성단형(vis-network) 지식 그래프에서 **선택된 세션의 뿌리 노드(Root Node)**가 자동으로 강조 및 포커스(`focus()`)되도록 개선하는 아키텍처 및 컨트롤러 규격서입니다.

---

## 1. 배경 및 문제점 분석

### 1.1 현상 진단
1. **생각나무(Markmap) 마인드맵**:
   * 기존 로직(`buildMarkmapMarkdown`)은 과거 5개 티켓(`MGTT-25938 쿠폰`, `MGTT-25184 GNB`, `MGTT-25076 여행네컷`, `MGTT-25353 레벨`, `Core 시스템`)이 정적으로 하드코딩되어 있었습니다.
   * 사용자가 오늘 새로운 작업이나 세션에서 질의를 전송하면, 신규 질의가 최상단 뿌리가 되지 못하고 **과거 티켓 카테고리 내부의 하위 가지(Leaf)**로 억지로 편입되어 데이터 인과관계를 파악하기 어렵습니다.
2. **성단형(vis-network) 성단 그래프**:
   * 노드 메타데이터(`nodes_data`)에 `session_id`가 누락되어 있어, 사용자가 상단 세션 드롭다운이나 테이블에서 특정 세션을 선택하더라도 그래프에서 해당 세션의 노드가 무엇인지 식별할 수 없습니다.
   * 선택된 세션의 **뿌리 노드(최초 사용자 질의)**로 카메라가 줌인(`focus()`)되거나 시각적으로 강조(Highlight)되는 인터랙션이 부재합니다.

---

## 2. 아키텍처 및 개선 설계

### 2.1 생각나무 (Markmap) 질의 중심 뿌리 계층 구조 (Root-first Hierarchy)
과거 하드코딩 카테고리를 완전히 제거하고, **"세션 / 신규 질의 중심의 인과관계 트리"**로 개편합니다.

```
[🌿 Giyeok 생각나무 마인드맵]
 ├── 🎯 [Root / 신규 질의] "79c01e5 커밋 일반레벨 복원 배치 결과 검증..." (🔥 현재 선택 세션)
 │    ├── 💡 [적용 해결책 & 아키텍처] "Level.Result 전이 분기 및 롤백 로직..."
 │    ├── 🔗 [회수된 과거 연관 지식 (Referenced)]
 │    │    ├── 📌 #node_1: "여행전문가 만료 배치 롤백 정책..." (적합도 95%)
 │    │    └── 📌 #node_2: "스냅샷 부재 시 예외 처리 핸들러..." (적합도 88%)
 │    ├── 🌿 [실행 서브스텝 (Sub-steps)] "Git diff 분석 ➔ 배치 진입점 대조 ➔ 단위테스트 검증"
 │    └── 🏷️ [에피소드 메타] 등급: [GOLD] | LOC: 45줄 | 비용: $0.0305 | 가중치: 3.50x
 └── 📂 [과거 세션 지식 뿌리들] (최근 활동 시간순 정렬)
      ├── 🎯 [Session 01a04236] "Gmarket XML 암호화 분기 우회..."
      └── 🎯 [Session 01a03eb6] "GNB 가이드 툴팁 캐시 만료..."
```

* **동작 규칙**:
  1. 상단 필터에서 특정 세션(또는 `🔥 최신 활성 세션`)이 선택된 경우:
     * 해당 세션의 **사용자 질의(Problem)가 최상위 단독 뿌리(Root)**로 생성됩니다.
     * 그 아래 가지로 **[적용 해결책]**, **[연관 참조 기억(Referenced Memories)]**, **[세부 메타데이터]**가 펼쳐집니다.
  2. `전체 (All Sessions)`를 보는 경우:
     * 하드코딩된 과거 티켓이 아니라, **최근 세션별 / 프롬프트 질의별**로 그룹화되어 최신 질의가 최상단에 배치됩니다.

---

### 2.2 성단형 (vis-network) 세션 뿌리 노드 자동 포커스 및 하이라이트

1. **Python 백엔드 (`MemoryHandler.get_graph_data()`)**:
   * 각 노드 데이터에 `session_id`, `is_session_root`, `prompt_summary`를 명시적으로 주입합니다.
   * 세션 내에서 가장 이른 타임스탬프를 가진 노드 또는 사용자 첫 프롬프트를 `is_session_root: true`로 마킹합니다.
2. **JavaScript 프론트엔드 (`analyze_usage.py`)**:
   * 세션 선택 시(`onFilterChange`, `selectSessionFilter`):
     * 선택된 세션의 노드들을 성단에서 탐색합니다.
     * 해당 세션의 뿌리 노드(Root Node) ID를 식별하여 **`network.focus(rootId, { scale: 1.4, animation: ... })`**를 호출합니다.
     * 선택된 세션의 노드는 **황금빛 링/보더 강조 및 크기 확대(Glow & Scale-up)**, 연결된 엣지는 선명하게 하이라이트하고, 무관한 노드는 반투명(Opacity 0.15) 처리하여 시각적 몰입도를 극대화합니다.

## 3. 세부 구현 인터페이스

### 3.1 `MemoryHandler.get_graph_data()` 확장
* `session_id`: 노드 텍스트 또는 memories 테이블 태그에서 파싱된 고유 세션 ID 보존
* `is_session_root`: 세션별 첫 질문 노드 플래그
* `session_map`: 프론트엔드가 즉시 세션별 노드 목록을 참조할 수 있도록 매핑 제공

### 3.2 프론트엔드 함수 규격
* `buildMarkmapMarkdown()`:
  * 현재 선택된 `targetSession` 감지
  * 선택 세션의 최신 질의 프롬프트를 루트 `#`로 승격
  * 연관 지식 엣지/참조를 서브 가지 `## 🔗 과거 연관 지식`으로 자동 렌더링
* `focusSessionInGraph(sessionId)`:
  * 미니 성단 캔버스 및 전체화면 성단 캔버스 모두에서 선택 세션의 뿌리 노드로 카메라 자동 이동 및 하이라이트 적용

---

## 4. 기대 효과
1. **질의 중심의 명확한 생각나무**: 새로운 질문을 던졌을 때, 내 질문이 나무의 뿌리가 되어 어디서 어떤 지식을 참조하고 어떤 해결책을 냈는지 한눈에 직관적으로 파악 가능.
2. **성단 그래프의 세션 연속성**: 대시보드에서 세션을 바꾸거나 프롬프트를 선택할 때마다 성단 속에서 해당 세션의 뿌리 노드로 매끄럽게 카메라가 비행(Fly-to)하여 데이터 탐색 편의성 대폭 증대.
